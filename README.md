# Weather Checker

A fast, lightweight web application built with vanilla TypeScript that fetches and displays real-time weather metrics—temperature, humidity, and wind speed—for any city.

## Features

- **Instant Weather Data**: View current temperature, humidity levels, and wind speed.
- **City Search**: Search for any city globally.
- **TypeScript First**: Written in pure TypeScript with zero framework overhead.
- **Responsive UI**: Clean interface designed for both desktop and mobile devices.

## Tech Stack

- **Language**: TypeScript
- **Styling**: CSS / HTML5
- **Build Tool / Bundler**: Vite
- **API**: OpenWeatherMap API
